# ⚖️ BMI Calculator

A simple Body Mass Index (BMI) Calculator built using **HTML, CSS, and Vanilla JavaScript**.

The application accepts height and weight values and calculates BMI through JavaScript DOM manipulation.

## ✨ Features

- Accept user height and weight.
- Calculate Body Mass Index.
- Display the calculated result.
- Interactive user interface.
- Responsive layout.

## 🛠️ Technologies

- HTML5
- CSS3
- Vanilla JavaScript

## 📚 JavaScript Concepts Practiced

- DOM manipulation
- `querySelector()`
- `addEventListener()`
- Input handling
- Reading input values using `.value`
- Type conversion using `Number()`
- Arithmetic operations
- Conditional statements
- Functions
- Dynamic content updates

## 🧮 BMI Formula

\[
BMI = \frac{Weight(kg)}{Height(m)^2}
\]

For example:

- Weight: 70 kg
- Height: 1.75 m

Result:

\[
BMI = \frac{70}{1.75^2} = 22.86
\]

## 🧠 Engineering Judgments

- Validate user input before performing calculations.
- Convert input values into appropriate data types.
- Handle invalid and missing values.
- Separate calculation logic from DOM manipulation.
- Consider boundary conditions.
- Display understandable feedback to users.
